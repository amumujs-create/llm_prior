# Frozen protocol — Prior Archetype Generalization v1

**Experiment ID:** `prior_archetype_generalization_v1`  
**Status:** frozen before execution

## Question

Does a simple, true monotonic-direction prior show the same distinction between
structural truth, observability, and far-OOD utility as the earlier, more
specific generator families?

## Generator and evaluation contract

Each trajectory is generated by a smooth random negative derivative,
`f'(t) = -s exp(g(t))`, where `g(t)` is a random Fourier series. Numerical
integration gives `f(t)`. Thus every trajectory is decreasing but there is no
shared exponential, polynomial, bound, or transition realization.

- Direction SNR: weak `.02`, medium `.08`, strong `.20`.
- Observed noise SD: `.005`, `.015`, `.030`; 100 independent draws per cell
  (900 trajectories).
- Observed support / selection split / D1-D3 bands are exactly those of E1.
- Candidates remain `P0, PD, PC, PB, PT`. Only `PD` has the true monotonic
  structural claim; `P0` is neutral and `PC/PB/PT` are incompatible.
- MSE and predictive BIC select independently; no composite score is formed.

## Endpoints

1. Direction-prior utility `RMSE(P0) - RMSE(PD)` by SNR/noise.
2. D3 selection regret and incompatible-selection rate for MSE and BIC.

## Guardrail

This cannot establish that direction alone determines an arbitrary monotone
continuation. It tests whether the prior-selection phenomena extend to a
qualitatively simpler archetype with only direction as shared truth.
